# Until Morning · Poker with friends

Приложение для домашних покерных турниров и кэша: настройте игру, рассадите участников и следите за таймером, блайндами и призовыми на общем табло. Запускается на вашем компьютере, интерфейс открывается в браузере, игры сохраняются локально.

**Пилотный релиз для полноценных домашних игр на одном устройстве.** Приложение уже использовалось в реальной игре; основные сценарии проверены автотестами и [хаотичными прогонами](docs/stress-test-2026-11-09.md). По обратной связи продолжаем улучшать логику и интерфейс.

## Быстрый запуск

Выберите свою систему и скачайте готовое приложение. **Go, Docker и Node.js устанавливать не нужно.**

| Система | Скачать | Что сделать |
| --- | --- | --- |
| Windows · Intel / AMD | [Скачать .exe](https://github.com/MrPrograMax/fun-poker-club/releases/download/v1.0.0/until-morning-v1.0.0-windows-amd64.exe) | Откройте скачанный файл |
| macOS · Intel и Apple Silicon | [Скачать универсальный .pkg](https://github.com/MrPrograMax/fun-poker-club/releases/download/v1.0.0/until-morning-v1.0.0-macos-universal.pkg) | Установите и откройте Until Morning из «Программы» |
| Linux · Intel / AMD | [Скачать .run](https://github.com/MrPrograMax/fun-poker-club/releases/download/v1.0.0/until-morning-v1.0.0-linux-amd64.run) | Разрешите исполнение файла и запустите его |

Для устройств ARM: [Windows ARM64](https://github.com/MrPrograMax/fun-poker-club/releases/download/v1.0.0/until-morning-v1.0.0-windows-arm64.exe) · [Linux ARM64](https://github.com/MrPrograMax/fun-poker-club/releases/download/v1.0.0/until-morning-v1.0.0-linux-arm64.run). Для Mac выбирать архитектуру не нужно.

Браузер откроется автоматически — можно настраивать игру. Если он не открылся, перейдите на [localhost:8080](http://localhost:8080). Сборки пока без подписи доверенного издателя: система может запросить разрешение на первый запуск. На macOS после попытки открыть установщик разрешение доступно в «Системные настройки → Конфиденциальность и безопасность».

<details>
<summary>Запуск Linux из терминала</summary>

В папке со скачанным файлом выполните:

```sh
chmod +x until-morning-v1.0.0-linux-amd64.run
./until-morning-v1.0.0-linux-amd64.run
```

Для ARM замените `amd64` на `arm64` в имени файла.

</details>

На Windows/Linux оставьте окно программы открытым на время игры; остановка — **Ctrl+C**. На macOS приложение работает без терминала; остановка — **Until Morning → Завершить (⌘Q)**. Закрытие вкладки браузера не останавливает сервер.

Игры и архив сохраняются в постоянной папке пользователя и остаются при перемещении или обновлении программы. **При переходе со старого ZIP-варианта перенесите сохранения** по [инструкции](docs/development.md#сохранения): в ней указаны пути для каждой ОС и условия автоматического переноса.

<details>
<summary>Другие способы запуска: переносной ZIP и исходники</summary>

ZIP-архивы доступны в [Assets релиза](https://github.com/MrPrograMax/fun-poker-club/releases/latest). Распакуйте архив целиком и используйте `start.cmd` на Windows, `start.command` на macOS или `start.sh` на Linux. Этот вариант хранит игры в `data` рядом с запускатором — переносите всю папку при обновлении.

Для запуска исходников нужен [Go 1.24+](https://go.dev/dl/): `go run ./cmd/until-morning`. Без открытия браузера: `go run ./cmd/until-morning -open-browser=false`.

Структура проекта, сборка и тесты — в [руководстве для разработки](docs/development.md).

## Основные возможности

- **Турниры и кэш:** настройки стеков, блайндов и взносов; учёт докупок и результатов.
- **Структура турнира:** автоподбор блайндов, редактирование уровней и перерывов, добавление уровней и продление текущего во время игры.
- **Рассадка:** до 200 участников, несколько столов, автоматический выбор места и подсказки сохранённых имён и ников.
- **Табло:** крупный таймер, текущие и следующие блайнды, пауза, звуковой сигнал и полноэкранный режим.
- **Призовые и баунти:** распределение призов по процентам, фиксированное и прогрессивное баунти с настройкой доли выплаты.
- **Управление игроками:** поиск по имени и нику, фильтры по столу и выбывшим, поздняя регистрация, ре-энтри и аддоны. После выбивания карточка остаётся доступной для ре-энтри без обновления страницы.
- **МТТ:** предложение объединить или сбалансировать столы с минимальным числом пересадок. Предпросмотр мест, финальный стол только для оставшихся игроков, отмена рассадки. Выбывание освобождает место; ре-энтри возвращает того же игрока на свободный стул. Схему стола можно поворачивать без изменения номеров мест.
- **Фризаут:** вручную или после выбранного перерыва; условия аддона можно изменить, ре-энтри — разрешить с подтверждением ведущего.
- **Итоги игры:** места, выплаты и статистика игроков — выбивания, ре-энтри, аддоны; для кэша — входы и докупки. При досрочном завершении неопределённые места остаются незаполненными.
- **Выгрузка JSON:** введённое имя или ФИО (`name`), ник (`nick`), взносы, ре-энтри, аддоны, выбивания и выплаты. В формате `schemaVersion: 2` отсутствующее имя или ник записываются как `null`, без подстановки «Игрок N». Суммы — в рублях, неопределённые результаты — `null`. ID и история действий в файл не попадают.
- **Архив игр:** завершённые игры и предыдущая игра при создании новой сохраняются на устройстве. Просмотр выплат, статистики, структуры и событий не меняет текущую игру. При отмене завершения архив обновляется.
- **История действий:** журнал, последовательная отмена последних операций и сохранение текущей игры вместе с доступными отменами после перезапуска.

Сервис ведёт учёт денег, но не принимает платежи. Управление с другого устройства с обновлением табло в реальном времени пока не реализовано.
