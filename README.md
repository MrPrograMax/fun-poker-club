# Until Morning · Poker with friends

Веб-сервис для покера с друзьями: настройте игру, рассадите участников и следите за таймером, блайндами и призовыми на общем табло. Поддерживает турниры и кэш. Работает локально на Go.

## Быстрый запуск

1. Скачайте архив `until-morning-…` для своей системы из [последнего релиза](https://github.com/MrPrograMax/fun-poker-club/releases/latest).
2. Распакуйте его и запустите файл:

   | Система | Файл запуска |
   | --- | --- |
   | Windows | `start.cmd` |
   | macOS | `start.command` |
   | Linux | `./start.sh` |

3. Браузер откроется автоматически — можно настраивать игру. Если окно не открылось, перейдите на [localhost:8080](http://localhost:8080) вручную.

Для Intel/AMD выбирайте архив `amd64`, для ARM и Mac с Apple Silicon — `arm64`. **Go, Docker и Node.js устанавливать не нужно.**

Окно запуска оставьте открытым на время игры; остановка — **Ctrl+C**. Игры сохраняются в папке `data` рядом с приложением — переносите её при обновлении.

Если скачали исходники репозитория, установите [Go 1.24+](https://go.dev/dl/) и используйте тот же файл запуска в корне проекта или команду `go run . -open-browser`. Для запуска без браузера: `go run .` или запускатор с параметром `-open-browser=false`.

## Основные возможности

- **Турниры и кэш:** настройки стеков, блайндов и взносов; учёт докупок и результатов.
- **Структура турнира:** автоподбор блайндов и уровней под желаемую длительность, ручная настройка и перерывы.
- **Рассадка:** до 200 участников, несколько столов, автоматический выбор места и подсказки сохранённых имён и ников.
- **Табло:** крупный таймер, текущие и следующие блайнды, пауза, звуковой сигнал и полноэкранный режим.
- **Призовые и баунти:** распределение призов по процентам, фиксированное и прогрессивное баунти с настройкой доли выплаты.
- **Управление игроками:** поздняя регистрация, выбывания, ре-энтри и аддоны. Фризаут с возможностью изменить условия аддона; допуск игроков решает ведущий.
- **История действий:** журнал, отмена операций и сохранение текущей игры после перезапуска.

Сервис ведёт учёт денег, но не принимает платежи. Управление с другого устройства с обновлением табло в реальном времени пока не реализовано.
